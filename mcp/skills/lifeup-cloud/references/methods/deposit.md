# deposit

Source: lifeup-wiki `docs/zh-cn/guide/api.md` (may lag).

**方法名：**deposit

**说明：**存款，会进行合法性校验（金币余额是否充足）。

**示例：**[lifeup://api/deposit?amount=500](lifeup://api/deposit?amount=500)

**解释：**存款 500 金币。

| 参数   | 含义     | 取值          | 示例 | 是否必须 | 备注 |
| ------ | -------- | ------------- | ---- | -------- | ---- |
| amount | 存款数量 | 大于 0 的数字 | 100  | 是       | -    |

**返回值：**

| 参数   | 含义         | 取值   | 示例 | 是否必须 | 备注 |
| ------ | ------------ | ------ | ---- | -------- | ---- |
| result | 操作是否成功 | 布尔值 | true | 是       | -    |
